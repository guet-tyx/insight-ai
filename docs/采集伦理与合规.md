# 采集伦理与合规（Collector 使用规范）

Insight AI 的采集能力（TLS 指纹抓取 / Stealth 浏览器 / RSS 解析）**仅用于
公开可访问信息的检索与分析**。使用前请阅读并遵守：

## 基本原则
1. **遵守 robots.txt 与目标站点服务条款**：采集前尊重站点的 robots 声明；
   禁止对明确禁止爬取的资源进行采集。
2. **低频礼貌采集**：内置同域请求间隔（`COLLECTOR_POLITE_MIN_DELAY`，
   默认 2-5 秒随机）与频控窗口，避免对目标站点造成访问压力。
3. **仅公开信息**：不采集需要登录才能访问的私有内容，除非使用本人账号
   登录态且内容属于本人可见范围。
4. **不破解访问控制**：本项目的「验证码检测 + 人工接管」仅用于识别与提示，
   不包含自动破解验证码、绕过登录/付费墙的功能。
5. **数据使用边界**：采集数据仅用于学习、研究与个人分析；大规模商用采集
   请先取得目标站点授权。

## 技术实现与边界
- **TLS 指纹抓取（curl_cffi）**：仅模拟浏览器网络层特征，用于规避针对
  自动化客户端的无差别拦截（如百度百科的 403）；不绕过登录态与验证码。
- **Stealth 浏览器**：隐藏自动化检测标记（webdriver 等），用于正常访问
  公开页面；不包含任何验证码自动破解或登录凭据伪造。
- **登录态复用**：`COLLECTOR_BROWSER_PROFILE=default` 时复用本机 Chrome
  登录态 —— 仅限本机自有账号、本人可见内容、低频使用；不要把账号凭据
  写入任何配置或代码仓库。

## 风险提示
- 采集公开网页仍可能违反个别站点的服务条款（ToS），由此产生的账号风险
  由使用者自行承担。
- 请勿将本项目用于：批量抓取个人信息、绕过付费墙/版权保护、DDoS 或
  干扰目标站点正常服务等用途。
